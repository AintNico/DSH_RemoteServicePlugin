# DSH Remote 1.1.0

用手机远程控制 DSH：看会话、收发消息、审批工具调用、双向传文件。

## 下载

| 文件 | 用途 | 装在哪 |
|---|---|---|
| `DSH-Remote-1.1.0-android.apk` | 手机客户端 | Android 8.0+ |
| `DSH-Remote-1.1.0-desktop-win-x64.zip` | 桌面客户端（自包含，免 .NET 运行时） | Windows 10 1809+ |
| `DSH-Remote-1.1.0-plugin.zip` | DSH 插件（服务端） | 跑 DSH 的电脑 |

## 安装顺序

1. **插件**先装：解压后把目录路径填到 DSH 的 `install_bundle`，启用插件，它会监听 `7317`
2. **桌面端**解压双击 `DshRemote.exe`，和插件同机免配对，左下角能看到手机访问地址和配对码
3. **手机**装 APK，填地址 + 配对码完成绑定

从 1.0.0 升级上来的，**不需要重新配对**：令牌继续有效，插件会自动迁移旧的设备记录。

详细步骤：[docs/INSTALL.md](https://github.com/AintNico/DSH_RemoteServicePlugin/blob/main/docs/INSTALL.md)

## 这个版本新增

**连接更稳**

- 断线重连改为指数退避（1s→30s，带抖动），不再固定 3 秒硬撞
- Wi-Fi 恢复时立即重连，不等退避计时器
- 断线状态实时反映到界面和通知栏

**授权更省心**

- 令牌改为 **24 小时滑动有效**：每次成功请求都把有效期推后一天，日常使用不必重新配对，连续闲置一天才失效
- 手机带稳定设备标识，重配只刷新同一行，管理列表里一台设备一条
- 过期或被吊销时，App 自动回配对页并提示

**审批**

- 多张审批卡改为可折叠托盘：最多占屏高 34%，内部滚动，标题显示「待审批 N 项」，点击折叠
- 不再只显示当前会话的审批：其它会话的审批也显示（标注「其它会话」），离开聊天页时到达的会暂存
- 每条审批独立通知，不再互相覆盖，处理后自动撤销

**文件**

- 工作区浏览支持**多选**：长按进入选择模式，批量「分享所选」或「保存所选」
- 手机端多文件发送合并为一条消息

**列表与安全**

- 运行中的工作区自动置顶（手机端与桌面端一致）
- 「解除配对」加二次确认，取消则完全不变

## 要求

- DSH 需提供 `sessionController`、`sessionQuery`、`workspaceRegistry` 服务
- 手机和电脑需在同一局域网（或自行开隧道）
- Windows 防火墙需放行 `7317` 入站（安装说明里有命令）

## 已知限制

- 没有中转服务器，公网访问依赖隧道工具
- QQ/微信聊天文件在应用私有目录，系统不允许第三方读取，需用「分享 / 用其他应用打开」递进来
- 桌面端必须和插件在同一台电脑上
