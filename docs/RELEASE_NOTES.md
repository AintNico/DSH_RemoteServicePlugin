# DSH Remote 1.2.0

用手机远程控制 DSH：看会话、收发消息、审批工具调用、双向传文件。

## 下载

| 文件 | 用途 | 装在哪 |
|---|---|---|
| `DSH-Remote-1.2.0-android.apk` | 手机客户端 | Android 8.0+ |
| `DSH-Remote-1.2.0-desktop-win-x64.zip` | 桌面客户端（自包含，免 .NET 运行时） | Windows 10 1809+ |
| `DSH-Remote-1.2.0-plugin.zip` | DSH 插件（服务端） | 跑 DSH 的电脑 |

## 安装顺序

1. **插件**先装：解压后把目录路径填到 DSH 的 `install_bundle`，启用插件，它会监听 `7317`
2. **桌面端**解压双击 `DshRemote.exe`，和插件同机免配对，左下角能看到二维码、地址和配对码
3. **手机**装 APK，扫桌面上的二维码即可

从 1.1.0 升级上来的，**不需要重新配对**：令牌继续有效。

详细步骤：[docs/INSTALL.md](https://github.com/AintNico/DSH_RemoteServicePlugin/blob/main/docs/INSTALL.md)

## 这个版本新增

**扫码配对**

- 桌面端「配对码」弹窗里多了一张二维码，编码的是深链
  `dshremote://pair?url=…&code=…`
- 手机三种方式任选：**系统相机扫码**（识别后直接唤起 App）、App 内「扫码连接」、或手填
- 开启 SSH 隧道后，二维码自动换成公网地址，不用手动改
- 点「重新生成」时数字和二维码**一起**更新

**连接与配对更可靠**

- 配对码改为**有效期内可重复使用**（原来一次性，第二次扫必然 `no-pairing`）
- 二次扫码不再静默：地址相同且令牌有效 → 提示「已连接到 …，无需重新配对」
- 令牌已失效（插件重置过）→ 用扫到的码**自动重新配对**，不再卡死
- 2 秒内的重复投递只处理一次，避免相机冷启动的重复回调

**其他修复**

- 应用内扫码的预览比例不再被拉伸（按传感器比例裁剪填充）
- 审批/提问托盘、会话标题、实时列表等沿用 1.1.0 的能力

## 要求

- DSH 需提供 `sessionController`、`sessionQuery`、`workspaceRegistry` 服务
- 手机和电脑需在同一局域网（或自行开隧道）
- 应用内扫码需要相机权限；用系统相机扫码则不需要
- Windows 防火墙需放行 `7317` 入站（安装说明里有命令）

## 已知限制

- 没有中转服务器，公网访问依赖隧道工具
- 二维码里含 5 分钟有效的配对码，只在本机 `127.0.0.1` 可取，桌面端负责显示
- QQ/微信聊天文件在应用私有目录，系统不允许第三方读取，需用「分享 / 用其他应用打开」递进来
